# Never Forgetting Ledger (NFL)

## Project Overview

**Project Name:** NFL  
**Repository Location:** C:\dev\fl  

Never Forgetting Ledger (NFL) is a permanent integrity ledger for cryptographic hashes. It allows systems and users to commit a hash once, store it with a timestamp, and look it up or verify it at any time. NFL ensures that important hashes are never lost and can always be independently verified.

## Languages/Stacks

- PowerShell
- SQLite (for storing the ledger)
- YAML (for configuration files)
